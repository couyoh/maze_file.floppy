File Explorer Maze
==

Boot this disk, then walk to a
number in the maze to open it.

Controls:
- Arrows: move
- Ctrl+C: back to this menu
- N / P: next / prev page
  (if more than 8 items)
- F1: Help (opens this file)

Restrictions:
- Don't delete README.TXT
  (F1: Help stops working)
- No folder support
  (just shows a message)

Notes:
- Safe to rename files, edit
  text, or add files from
  Windows / Mac / Linux
- Changes appear next boot
