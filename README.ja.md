# maze_file.floppy - Boot Maze. Walk to your files.

[English](README.md) | 日本語 (Japanese)

![迷路型ファイルエクスプローラ](images/index.gif)

**迷路型ファイルエクスプローラ**です。
フロッピー上のファイルが、ランダムに生成された迷路と共に表示されます。迷路をクリアするとファイルが開けます。

- `.COM` ファイルは、DOS 形式のプログラムとして実行可能です。
- それ以外のファイルは、テキストビューアで表示されます。

本フロッピーはWindows、macOS、Linuxなどでマウントして、ファイルの追加、名前の変更、編集ができます。

[1.44MB GAME_DEV CONTEST](https://2pgarcade.com/contest-144mb.html) への応募作品です。

## 同梱プログラム

| ファイル      | 説明      |
| ------------ | -------- |
| `MAZE.COM`   | 迷路ゲーム |
| `HASAMI.COM` | はさみ将棋 |

### Windows でプログラムを動かす

同梱の `.COM` ファイルは、ディスクから起動しなくても Windows 上で直接動きます。ただし、Windows XPなどの16ビットの DOS プログラムが動く Windows が必要です。64ビット版の Windows では動きません。

- Windows の言語が英語以外に設定されているとエラーになります。英語へ切り替えてください。
- [ReactOS](https://reactos.org/) でも動きます。

![ReactOS で動く HASAMI.COM](images/reactos.png)

## 必要なもの

- [NASM](https://www.nasm.us/)
- [GNU Make](https://www.gnu.org/software/make/)
- シミュレータで動かす場合は [QEMU](https://www.qemu.org/) または [Bochs](https://bochs.sourceforge.io/)（任意）

Dev Container（`.devcontainer/`）で、これらをすべてインストールできます。

Debian/Ubuntu では次のコマンドでインストールできます。

```sh
sudo apt install nasm make qemu-system-x86 qemu-system-gui bochs-x
```

## ビルドと実行

```sh
make          # ビルド
make qemu     # QEMU でイメージを起動
make debug    # Bochs のデバッガ付きでイメージを起動
make clean    # クリーン
```

フロッピーに対応したエミュレータであれば、`build/floppy.img` をフロッピーイメージとして設定してください。

### 実機で動かす

`build/floppy.img` をフロッピーディスクに書き込み、フロッピードライブからPCを起動します。BIOSモードで起動する必要があります（[制限事項](#制限事項)を参照）。

**Linux**

フロッピードライブが `/dev/fd0` の場合:

```sh
sudo dd if=build/floppy.img of=/dev/fd0 bs=512 conv=fsync
```

**Windows**

Windowsの標準機能では書き込みできません。ディスクイメージをそのままフロッピーに書き込めるツールを使用してください。（もしかするとPowershellで書き込めるかもしれないです。）

## 操作方法

ファイルエクスプローラ以外の画面では、`Ctrl+C` でメニューに戻ります。

**ファイルエクスプローラ（迷路）**

| キー           | 動作                               |
| ------------- | ---------------------------------- |
| ↑ / ↓ / ← / → | 移動                                |
| `N` / `P`     | 次 / 前のページ（項目が8個より多い場合） |
| `F1`          | `README.TXT` を開く                 |

**テキストビューア**

| キー  | 動作      |
| ----- | -------- |
| ↑ / ↓ | スクロール |

**はさみ将棋**

各手番で、次の順にキーを使います。

| 手順  | キー           | 動作                                                                   |
| ---- | ------------- | -------------------------------------------- |
| 1    | ← / →         | 自分の駒を選ぶ                                 |
| 2    | `Enter`       | 駒決定。移動できるマスが強調表示                  |
| 3    | ↑ / ↓ / ← / → | 強調表示されたマスにカーソルを動かす               |
| 4    | `Enter`       | そのマスへ移動。駒の上で `Enter` を押すとキャンセル |

## 制限事項

- BIOSのみで動作します。UEFIの場合はCSM（レガシーブート）を有効にしてください。
- フォルダは開けません。
- `README.TXT` を削除すると F1 のヘルプが使えなくなります。
- テキストビューアは、ファイルの先頭 2 KiB または 200 行です。長い行は折り返しますが、折り返した場合でも行数に含みます。
- シャットダウンは QEMU、Bochs、VirtualBox でのみ動作します。

### 対応しているシステムコール

| 割り込み    | 動作                                         |
| ---------- | ------------------------------------------- |
| `int 0x20` | 終了してメニューに戻る                         |
| `int 0x21` | **`AH` の値にかかわらず**、終了してメニューに戻る |
| BIOSコール  | 使用可能                                     |

`int 0x21` はどれを呼んでも終了するので、DOSのシステムコールは使えません。代わりにBIOSコールを使用してください。

## プログラムを追加する

マウントしたイメージに `.COM` ファイルをコピーしてください。プログラムは[対応しているシステムコール](#対応しているシステムコール)に準拠してください。
